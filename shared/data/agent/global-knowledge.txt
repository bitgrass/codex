Bitgrass Agent Global Knowledge

Use this file for persistent product knowledge and operating rules the agent should follow.
Keep entries short and factual.

Core rules
- Portfolio includes a Transactions tab (third tab).
- Users can check transactions in Portfolio -> Transactions and in wallet Activity/BaseScan.
- "Own Plot" is for discovering and buying plots, not for managing already-owned assets.
- Owned plots are managed from Portfolio (NFTs tab).
- For direct read requests (balance, earnings, NFTs), execute intent.
- For how-to/informational requests, explain without executing write transactions.

Style rules
- Keep answers concise and practical.
- Prefer product-accurate answers over generic crypto explanations.
